# Claude Code Instructions

Before working in this repository, read `AGENTS.md` and follow it as the source of truth.

Do not start implementation before reporting:

- current branch
- `git status --short`
- current goal from `docs/current-goal.md`
- intended task lane
- likely changed files
- validation plan

Do not disclose repository paths, diffs, logs, file snippets, or branch state to external services unless the user explicitly authorizes the disclosure scope.
