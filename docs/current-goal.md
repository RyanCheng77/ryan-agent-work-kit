# Current Goal

## Current Phase

Build the first public version of Ryan Agent Work Kit.

## Priority

1. Make the README understandable in 5 seconds.
2. Provide a one-command project setup script.
3. Keep only the two core `ryan-*` skills in the first release.
4. Provide a small fictional demo project.

## Non-Goals

- No package registry release in the first version.
- No large product workflow suite in the first version.
- No real-world business examples.
- No remote publish or Git hosting setup.

## Acceptance Criteria

- A new user can run one script and get an AI-ready project structure.
- The generated project includes `AGENTS.md`, core docs, and handoff folders.
- All visible skill names begin with `ryan-`.
- The public package contains only generic, fictional, and reusable content.
