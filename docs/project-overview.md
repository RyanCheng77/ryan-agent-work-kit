# Project Overview

Ryan Agent Work Kit is a small open-source kit for making projects easier for AI coding agents to understand and handle.

## Main Idea

Most AI coding problems come from missing project context:

- The agent does not know the current goal.
- The agent does not know safe Git behavior.
- The agent does not know what validation is expected.
- Different tools repeat the same discovery work.

This kit fixes that by giving every project a simple file-based operating standard.

## Included

- Project governance templates.
- Personal preference templates.
- Two core Ryan skills.
- Setup and readiness scripts.
- A fictional demo project.

## First Release Shape

The first release should feel small, useful, and beginner-friendly. It should not ask users to learn the whole Ryan method before getting value.
