# Design Principles

Keep this demo's modules loosely coupled through explicit inputs, outputs, and documented contracts.

For UI or interaction work, check the relevant Nielsen heuristics:

- Make status visible.
- Match the user's language and task model.
- Preserve cancel, undo, and recovery paths.
- Prevent predictable errors.
- Keep choices visible and the screen focused.

Record a screenshot, manual scenario, or test as evidence for meaningful user-facing changes.
